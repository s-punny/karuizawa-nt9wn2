# 写真の置き場所

このフォルダに以下のファイル名で画像を置くと、ページ内のプレースホルダが
自動的に写真に差し替わります。**置かなければ何も壊れません**（枠のまま表示されます）。

| ファイル名 | 使われる場所 | 推奨サイズ・比率 | 状態 |
| --- | --- | --- | --- |
| `cover.jpg` | 表紙の背景（暗くかぶせて使用） | 縦長〜正方形 / 1600×2000px 程度 | 未 |
| `chapel-exterior.jpg` | ごあいさつ直後の写真の組（大きい方） | 横長 4:3 / 1200×900px 程度 | **あり** |
| `chapel-chandelier.jpg` | 同（小さい方・シャンデリア） | 横長 4:3 / 800×600px 程度 | **あり** |
| `chapel-interior.jpg` | 挙式会場カード | 4:3 / 1200×900px 程度 | **あり** |
| `dinner.jpg` | お食事会場カード | 4:3 / 1200×900px 程度 | 未 |
| `hotel.jpg` | ご宿泊カード | 4:3 / 1200×900px 程度 | 未 |
| `ogp.jpg` | LINE等でリンクを送ったときのサムネイル | 1200×630px | 未 |

## メモ

- 前撮り写真がなくても、軽井沢の風景・チャペル外観・林の写真などで十分に成立します。
  会場が決まったら公式サイトの写真を（許諾の範囲で）借りるか、下見のときに撮った写真でも構いません。
- 表紙の写真は暗い緑を重ねて使うので、多少明るくても・多少雑でも馴染みます。
  逆に「主役が写っている写真」よりは、**風景・光・空気感**が写っているものの方が合います。
- ファイルサイズは 1枚 500KB 以下を目安に。LINE から開いたときの表示が軽くなります。
- いま入っているチャペルの3枚は **540×400px / 280×200px と小さめ**です。
  そのため全幅の帯や表紙の背景には使わず、本文幅のなかで小さめに配置しています。
  もっと大きい元データが手に入ったら、同じファイル名で差し替えるだけで綺麗になります。
- `ogp.jpg`（LINEのサムネイル）はまだ未設置です。1200×630px の写真を置くと出るようになります。
  いまの3枚は解像度が足りないため、そのままの流用は避けています。
