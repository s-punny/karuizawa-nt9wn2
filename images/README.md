# 写真の置き場所

このフォルダに以下のファイル名で画像を置くと、ページ内のプレースホルダが
自動的に写真に差し替わります。**置かなければ何も壊れません**（枠のまま表示されます）。

| ファイル名 | 使われる場所 | 推奨サイズ・比率 |
| --- | --- | --- |
| `cover.jpg` | 表紙の背景（暗くかぶせて使用） | 縦長〜正方形 / 1600×2000px 程度 |
| `karuizawa.jpg` | ごあいさつ直後の全幅の写真帯 | 横長 16:6.5 / 2000×800px 程度 |
| `chapel.jpg` | 挙式会場カード | 4:3 / 1200×900px 程度 |
| `dinner.jpg` | お食事会場カード | 4:3 / 1200×900px 程度 |
| `hotel.jpg` | ご宿泊カード | 4:3 / 1200×900px 程度 |
| `ogp.jpg` | LINE等でリンクを送ったときのサムネイル | 1200×630px |

## メモ

- 前撮り写真がなくても、軽井沢の風景・チャペル外観・林の写真などで十分に成立します。
  会場が決まったら公式サイトの写真を（許諾の範囲で）借りるか、下見のときに撮った写真でも構いません。
- 表紙の写真は暗い緑を重ねて使うので、多少明るくても・多少雑でも馴染みます。
  逆に「主役が写っている写真」よりは、**風景・光・空気感**が写っているものの方が合います。
- ファイルサイズは 1枚 500KB 以下を目安に。LINE から開いたときの表示が軽くなります。
