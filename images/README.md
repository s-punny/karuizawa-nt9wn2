## メモ

- 前撮り写真がなくても、軽井沢の風景・チャペル外観・林の写真などで十分に成立します。
  会場が決まったら公式サイトの写真を（許諾の範囲で）借りるか、下見のときに撮った写真でも構いません。
- **表紙を差し替えるときは、ファイル名の末尾の番号を上げてください**
  （`cover-bouquet-3.jpg` → `cover-bouquet-4.jpg`）。`index.html` の `src` も一緒に直します。
  同じ名前で上書きすると、すでにページを開いたことのある人のブラウザが
  古い写真を表示し続けます。名前を変えれば確実に新しい方が出ます。
  他の写真も、一度配ったあとに差し替えるときは同じようにしてください。
- 表紙は写真を全面に敷くのをやめ、紙の上に**正方形のパネル**として置く作りにしました。
  かぶせも掛けないので、**そのまま見せて成立する一枚**を選んでください。
  枠が正方形なので**正方形の写真**なら切れずに収まります。別の比率だと中央が切り取られます。
- ファイルサイズは 1枚 500KB 以下を目安に。LINE から開いたときの表示が軽くなります。
- **表示サイズと元データの大きさを合わせる**のがこのページの写真の方針です。
  表示より極端に小さい写真はスマホの高精細な画面で粗く見えます。
  より大きい元データが手に入ったら差し替えてください（ファイル名の扱いは上のとおり）。
- `ogp-3.jpg` は `_ogp.html`（リポジトリ直下）を 1200×630 で表示して撮ったものです。
  表紙や名前を変えたら、あれを直して撮り直してください。
  **LINE はサムネイルを強くキャッシュするので、作り直したらファイル名の番号を上げること**
  （`ogp-3.jpg` → `ogp-4.jpg`。`index.html` の `og:image` も一緒に直します）。
- `icon5-*.png` は林のなかのチャペルのイラストです。ページの配色に合わせて
  色を振ってあります（金の太陽を珊瑚寄りに、緑を温かい側へ）。
  **iOS は角丸のマスクを自分で掛けるので、角を丸めた画像を入れないこと。**
  角丸の中に角丸が入って浮きます。元絵に角丸が焼き込まれている場合は、
  その内側を正方形で切り出してから使ってください。
  180 と 192 は**インデックスカラーではなく通常の RGB の PNG**にしてあります
  （Apple がアイコンに推奨しているのがこの形式のため）。512 は Android の
  スプラッシュ用なので、軽さを優先してインデックスにしています。
- **アイコンは端末に強く残ります。**作り替えたらファイル名も変えてください
  （`icon5-180.png` → `icon6-180.png` など）。`index.html` と `manifest.json` の
  両方を直す必要があります。
- ページの配色は表紙のブーケに合わせてあります（生成りの地・温かい墨・くすんだ薔薇茶）。
  表紙の写真を大きく変えるときは、`index.html` 冒頭の `:root` の色も見直すと揃います。
- `ogp.jpg`（LINEのサムネイル）はまだ未設置です。1200×630px の写真を置くと出るようになります。
- `spot-*.jpg`（観光の6枚）はすべて設置済みです。同じ名前で上書きすれば差し替わります。
  表示は `object-fit:cover` なので縦横比は揃っていなくても崩れません（中央が切り取られます）。
  ただし元データが小さいとスマホで粗く出ます。`spot-newart.jpg` は 547px 幅と小さめなので、
  大きい写真が手に入ったら同じ名前で差し替えると綺麗になります。
