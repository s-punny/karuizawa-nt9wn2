# 写真の置き場所

このフォルダに以下のファイル名で画像を置くと、ページ内のプレースホルダが
自動的に写真に差し替わります。**置かなければ何も壊れません**（枠のまま表示されます）。

| ファイル名 | 使われる場所 | 推奨サイズ・比率 | 状態 |
| --- | --- | --- | --- |
| `cover.jpg` | 表紙の背景（墨緑をかぶせて使用） | 横長 / 1600×1040px 程度 | **あり** 1000×650 |

## メモ

- 前撮り写真がなくても、軽井沢の風景・チャペル外観・林の写真などで十分に成立します。
  会場が決まったら公式サイトの写真を（許諾の範囲で）借りるか、下見のときに撮った写真でも構いません。
- 表紙の写真は暗い緑を重ねて使うので、多少明るくても・多少雑でも馴染みます。
  逆に「主役が写っている写真」よりは、**風景・光・空気感**が写っているものの方が合います。
- ファイルサイズは 1枚 500KB 以下を目安に。LINE から開いたときの表示が軽くなります。
- **表示サイズと元データの大きさを合わせる**のがこのページの写真の方針です。
  1000×650 の2枚（`cover.jpg` / `chapel-nave.jpg`）は大きく使い、
  280×200 の `chapel-chandelier.jpg` は重ねる小さな一枚にとどめています。
  より大きい元データが手に入ったら、同じファイル名で差し替えるだけで綺麗になります。
- `cover.jpg` は grayscale + 墨緑のかぶせで沈めて使うので、多少の粗さは目立ちません。
  スマホでは縦に大きくトリミングされるため、**中央に主役があって上下に余白のある構図**が向いています。
- `ogp.jpg`（LINEのサムネイル）はまだ未設置です。1200×630px の写真を置くと出るようになります。
